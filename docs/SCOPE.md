# Release scope

The release is a single-owner engineering assistant: authenticated conversations,
editable preferences, three versioned skills, scoped connections, background
schedules, exact issue approval, notes, evidence and receipts.

The original Flask command runner remains as historical source and is excluded
from the release image and imports. Shell execution, arbitrary HTTP retrieval,
email, calendars, voice, Telegram and swarms are not offered in the release UI.

No remote deployment, publishing, repository visibility change, account creation,
GitHub issue creation against a live repository, or submission is authorized by
this local rebuild. Live tests are explicitly separated from controlled transports.
