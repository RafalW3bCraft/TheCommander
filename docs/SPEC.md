# API and state specification

The canonical wire contract is [openapi.json](openapi.json), generated by
`uv run python -m scripts.export_openapi`. Frontend types derive from it with
`npm --prefix frontend run api:types`.

API families: `/api/auth`, `/api/memory`, `/api/conversations`, `/api/runs`,
`/api/schedules`, `/api/connections`, `/api/actions`, `/api/skills`, `/api/notes`,
`/api/worker`, `/api/budgets`. Owner authentication applies to every resource.
Cookie-authenticated writes require `X-CSRF-Token`; browser Origin must match
APP_ORIGIN. Errors have `error.code` and `error.message`; validation fields omit
submitted values. Conflicting revisions return 409; missing other-owner IDs 404.

Run states: queued → running → succeeded / failed / waiting_approval / uncertain
/ cancelled. Approval returns a waiting run to the queue. A lost external write
response becomes uncertain, never automatically retried. Action states bind
owner, run, tool, exact argument hash, configured repository, connection revision,
and a 30-minute expiry. Edits reset approval. Successful receipts record provider
object number, canonical URL and confirmation timestamp.

Memory types are explicit, inferred, episodic, task, evidence and procedural.
Only explicit/inferred preferences enter cross-session recall. Explicit entries
win on key conflicts. Expired preferences do not enter context. Raw conversations,
evidence and task outcomes live in separate relational tables, not as permissions.
No derived embedding or summary index exists, so deleted memory is immediately
absent from future recall. Old conversation messages may still mention it until
the conversation is deleted.

Budgets: step count, context characters, output tokens, run duration, daily run
count and daily model tokens are configurable. Unknown usage reserves the maximum
request allowance. Currency limits fail closed without operator-supplied model
prices. No model prices or provider usage are invented. Provider timeout is
bounded per request. Unknown cost remains null in activity diagnostics.
